# 💎 Onyx Assessment Platform v3.1
### *The Ultimate Enterprise Educational & Assessment Ecosystem*

Onyx is a high-performance, immersive assessment platform designed for professional technical evaluation and academic training. Built with **Cyber-Terminal Aesthetics** and **Glassmorphism 3.0**, it provides a premium user experience coupled with a robust heuristic engine.

---

## 🚀 Key Features

### 1. Massive Knowledge Base (Onyx Database)
- **5,000+ Procedural Questions**: Covering 10 diverse domains including Python, Cybersecurity, Machine Learning, Mathematics, and more.
- **5 Difficulty Tiers**: From *Easy* for beginners to *Impossible* for elite operators.

### 2. Gamified Progression System
- **XP & Leveling**: Gain Experience Points (XP) through successful missions.
- **Level-Gating**: Advanced subjects and difficulties are locked behind level requirements, ensuring a structured learning path.
- **Global Ranking**: Compete for the top position in the operator rankings.

### 3. Emergency Random Challenges & Onyx Network
- **Onyx Network Tracker**: Live simulated active operator count with periodic network updates in the sidebar.
- **Dynamic Arena Matchmaking**: Search for opponents in the "Arena de Combate". Simulates network ping scans and dynamically displays available opponents globally.
- **High-Stakes Alerts**: Periodic "Desafio Prioritário" alerts with sound feedback.
- **Risk/Reward**: High XP gains for success, but significant XP penalties for failure.

### 4. Heuristic Performance Engine
- **Profile Insights**: Real-time analysis of your strengths and weaknesses.
- **Adaptive Recommendations**: Personalized study paths generated based on your accuracy and response time.

### 5. Enterprise-Grade UI/UX
- **Glassmorphism 3.0**: A stunning, semi-transparent interface with vibrant accents.
- **Fully Responsive**: Optimized for ultra-wide monitors, tablets, and mobile devices.
- **Offline Persistence**: Uses `IndexedDB` (OnyxEliteDB) for zero-latency local storage without needing a backend server.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+).
- **Styling**: Modern CSS3 with Utility-First architecture and custom animations.
- **Database**: IndexedDB (Client-side persistent storage).
- **Architecture**: Modular Script System (OnyxCore, OnyxEngines, OnyxUI).
